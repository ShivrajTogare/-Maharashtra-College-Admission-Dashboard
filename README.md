# 🎓 Maharashtra College Admission Dashboard

## 📊 Power BI Analytics Project
<img width="1312" height="733" alt="dashbord" src="https://github.com/user-attachments/assets/904694bc-80af-498d-848b-fd5f46f9f613" />


An interactive Power BI dashboard designed to analyze college admission applications across Maharashtra.

The dashboard provides insights into application trends, admission status, student demographics, entrance scores, fees, courses, cities, and college-wise performance.

---

## 🎯 Project Overview

The Maharashtra College Admission Dashboard transforms raw admission application data into meaningful and interactive visual insights.

### 🔍 Key Areas of Analysis

- 👥 Total Applications
- ✅ Approved Applications
- ❌ Rejected Applications
- ⏳ Pending Applications
- 📍 City-wise Applications
- 🏫 College-wise Performance
- 📚 Course-wise Applications
- 👨‍🎓 Student Demographics
- 💰 Average Fees
- 📝 Average Entrance Score
- 🌳 Department-wise Demand

---

## 🎯 Objectives

- 📈 Monitor admission application trends
- ✅ Analyze approval and rejection performance
- 👨‍🎓 Understand student demographics
- 🏫 Compare college performance
- 💰 Analyze college fees
- 📝 Compare entrance scores
- 📚 Identify popular courses and departments
- 📊 Support data-driven admission decisions

---

## 🗂️ Dataset

The project uses an application-level dataset containing college admission records across Maharashtra.

### Key Columns

| Column | Description |
|---|---|
| 🆔 Application ID | Unique application identifier |
| 🏷️ Status | Approved / Rejected / Pending |
| 📅 Admission Date | Date of application/admission |
| 👨‍🎓 Gender | Student gender |
| 📍 City | Student/application city |
| 🏫 College | College name |
| 📚 Course | Applied course |
| 🏢 Department | Department |
| 💰 Fees | College/course fees |
| 📝 Entrance Score | Student entrance examination score |
